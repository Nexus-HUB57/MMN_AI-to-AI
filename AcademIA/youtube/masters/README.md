# Masters oficiais da AcademIA Nexus

Este diretório contém os masters canônicos das videoaulas prontos para upload ao canal YouTube da AcademIA Nexus.

Padrão de render (auditoria Nexus 2026-07-24):

- Resolução: 1280x720 @ 25fps
- Vídeo: H.264
- Áudio: AAC 192kbps
- Duração alvo: 60 a 240 segundos por aula (execução original), com upgrade premium para até ~4 minutos quando a aula for cartão de visita (módulo 00)
- Slides oficiais: mínimo 5, máximo 10
